# INDUSTRIA — Industrial Design System & Visual Language

## 1. Design Philosophy
The INDUSTRIA visual identity departs completely from generic SaaS blues and purple gradients. Instead, it draws inspiration from high-precision CNC toolrooms, German machine tool dashboards, and raw fabricated alloys.

### Core Principles
- **Engineering Precision:** Dense data presentation, monospaced dimensional tags, clear tolerance metrics, and structured key-value specifications.
- **Warm Industrial Palette:** High-contrast neutral surfaces paired with a bold fiery forging amber-orange primary tone.
- **Micro-Interactions with Intent:** Subtle hover feedback, smooth stage progressions, tab switches, and milestone steppers without gratuitous or distracting animation.

---

## 2. Color Palette & Tokens

### Primary Brand
- **Forging Orange (Primary):** `#d4560a`
- **Primary Hover:** `#b34707`
- **Primary Light Surface:** `#fff7ed`
- **Primary Border Tint:** `#fed7aa`

### Neutral Surfaces
- **Background Base:** `#fafaf8` (Warm off-white)
- **Card Surface:** `#ffffff` (Pure white)
- **Subtle Surface:** `#f5f5f4` (Warm gray 100)
- **Border Neutral:** `#e7e5e4` (Stone 200)
- **Dark Industrial Command:** `#0c0a09` (Stone 950)

### Status & Pipeline Accents
- **Success / Accepted / Delivered:** Emerald (`#16a34a` / `#ecfdf5`)
- **Warning / Review / Pending:** Amber (`#d97706` / `#fffbeb`)
- **Engineering / Quoted / CAD:** Blue (`#2563eb` / `#eff6ff`)
- **Urgent / High Priority:** Rose (`#e11d48` / `#fff1f2`)

---

## 3. Typography
- **Headings:** Modern geometric sans-serif with industrial weight (`font-bold`, `tracking-tight`).
- **Body & Paragraphs:** Clean readable sans-serif with high contrast (`text-neutral-700`, `leading-relaxed`).
- **Technical Dimensions & Codes:** Monospaced typeface for SKUs, tolerances, GST numbers, and prices (`font-mono`).

---

## 4. Components & Elevation
- **Rounded Corners:** Consistent `rounded-xl` for cards and inputs; `rounded-2xl` for executive panels; `rounded-full` for badges.
- **Industrial Grid Overlay:** Subtle 24px micro-grid background pattern (`.bg-industrial-grid`) for blueprint aesthetic.
- **Elevations:** Soft micro-shadows (`shadow-xs`, `shadow-sm`, `shadow-md`) avoiding muddy drop-shadows.
